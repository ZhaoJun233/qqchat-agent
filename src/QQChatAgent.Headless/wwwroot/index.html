回复节奏

防止刷屏、控制发言手感。

长期记忆 · 人物画像

定期用模型把堆积的历史发言压缩成一段画像（代替“一堆原文”），token 降一个数量级。

表情包

机器人会自动把群友发的图收进表情包库，按下文语境挑图发出来；也会自己巡检并决定删哪些。 全库共用一份（不分会话）。

听音乐

有人在群里分享歌（网易云歌曲卡片/链接）时，机器人会去查歌名与歌词、下一份低码率音频， 自己分析波形（响度/动态/速度/段落起伏），再拿着这些实测事实跟群友接话。

网易云扫码登录、音源模板、音频识别模型都在「音频源接入」里（VIP 歌要登录后才有播放地址）。

语音消息

机器人可以用语音说话（模型在 JSON 里填 speak 字段时）。 合成走 Piper（CPU 就能实时出音）旁路服务，默认关闭 —— 语音比文字“重”，想让它偶尔开口再开。

换音色就是换一个 onnx 模型（音色即模型）；想复现某个特定人的音色需先拿到授权并单独训练。 试听用的是已保存的「TTS 服务地址」——改了地址先点保存再试听。

联网搜索

模型可以要求去网上查一下（JSON 里填 search 字段）或读一下某个网页（read 字段）， 查到的东西会作为事实交给它，下一轮再拿着事实回答 —— 而不是靠印象编。 默认走模型自带搜索（检索在模型服务商那边完成，结果自带来源）；它不可用时才回退到下面的搜索源。



          
为什么默认靠模型自带搜索：机房 / 云服务器 IP 常被搜索引擎当爬虫挡掉（回看板页或验证码），
            而模型服务商那边的检索不用额外密钥、不爬页面、结果还带来源。自建 SearxNG / MediaWiki 之类的接口可以把地址填到上面。
